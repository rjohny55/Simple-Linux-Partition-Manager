# 🖥️ Простой менеджер разделов Linux

[English](README.md) | **Русский**

Простой и удобный bash-скрипт для управления разделами дисков в Linux с интуитивно понятным текстовым интерфейсом.

## ✨ Особенности

- 📊 **Просмотр информации** о дисках и разделах
- 📏 **Изменение размера** разделов с расширением файловой системы
- ➕ **Создание новых** разделов
- ❌ **Удаление** существующих разделов
- 🔄 **Автоматическое расширение** файловых систем (ext2/3/4, XFS, BTRFS, NTFS)
- 🛡️ **Безопасное размонтирование** перед операциями
- 🔧 **Исправление GPT таблиц** при необходимости
- 🎨 **Цветовой вывод** для лучшей читаемости

## 📋 Поддерживаемые файловые системы

- **ext2/ext3/ext4** - полная поддержка
- **XFS** - расширение при монтировании
- **BTRFS** - расширение при монтировании  
- **NTFS** - с утилитой `ntfsresize`
- **FAT32** - ограниченная поддержка

## 🚀 Быстрый старт

### Требования
- Linux ОС
- Права root
- Утилиты: `lsblk`, `parted`, `blkid`, `findmnt`

### Установка и запуск

```bash
# Скачайте скрипт
git clone https://github.com/rjohny55/Simple-Linux-Partition-Manager.git
cd partition-manager

# Дайте права на выполнение
chmod +x slpm_ru.sh

# Запустите с правами root
sudo ./slpm_ru.sh
```

## 🎯 Использование

### Основное меню
После запуска вы увидите:
1. **Список всех дисков** с информацией о свободном месте
2. **Выбор диска** для управления
3. **Меню операций** с выбранным диском

### Доступные операции
- 📊 **Информация о диске** - подробные сведения о диске
- 📋 **Таблица разделов** - текущая структура разделов
- ➕ **Создать раздел** - создание нового раздела
- ❌ **Удалить раздел** - удаление существующего раздела  
- 📏 **Изменить размер** - расширение раздела с обработкой GPT

## ⚠️ Важные предупреждения

- **Всегда делайте бэкап** важных данных перед работой с разделами
- **Не прерывайте выполнение** операций с разделами
- **Убедитесь**, что раздел не смонтирован или может быть безопасно размонтирован

## 🔧 Пример работы

```bash
# Запуск скрипта
sudo ./slpm_ru.sh

# Пример расширения раздела:
# 1. Выбираем диск /dev/sda
# 2. Выбираем "Изменить размер раздела"
# 3. Выбираем раздел 2 (последний)
# 4. Подтверждаем размонтирование
# 5. Выбираем расширение на всё свободное место
# 6. Подтверждаем операцию
# 7. Скрипт автоматически расширяет раздел и файловую систему
```

## 🐛 Решение проблем

### Ошибка GPT таблицы
Если возникает ошибка:
```
Warning: Not all of the space available to /dev/sda appears to be used
```
Скрипт автоматически предложит исправить GPT таблицу.

### Раздел смонтирован
При обнаружении смонтированного раздела скрипт предложит:
- Размонтировать автоматически
- Продолжить без размонтирования (не рекомендуется)
- Отменить операцию
